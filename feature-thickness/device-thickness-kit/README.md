# device-thickness-kit

Комплект для работы с толщиномерами ЛКП (лакокрасочного покрытия). Перенесён из `packages/device-thickness` в рамках Волны D миграции (Session 19G).

## Происхождение
- **Исходный путь**: `packages/device-thickness/`
- **Дата переноса**: 24.11.2025
- **Сессия**: 19G
- **Статус исходного каталога**: UTILIZED (помечен для удаления после подтверждения)

## Структура
Содержит минимальную заглушку для работы с BLE толщиномерами (package.json).

## Связь с модулями
- Используется в `android/feature-thickness` для работы с BLE устройствами
- Интерфейсы: подключение, чтение замеров (40-60 точек кузова), статусы измерения
- Связь с LockController для выдачи толщиномера из терминала

## Планируемая интеграция
После завершения миграции TypeScript пакетов, логика должна быть адаптирована в Kotlin через JNI-обёртку или переписана нативно. Альтернативно может использоваться напрямую через Node-агент (`android/platform/ui/web/agent`).

## Использование
```bash
# Из корня репозитория
cd android/feature-thickness/device-thickness-kit
npm install
npm test
```

## Vault и секреты
- Если устройство использует закрытый протокол, требуется официальный SDK или письменное согласие вендора
- UUID сервиса и характеристик хранятся в конфигурации, не в коде
- Пути к Vault: см. `09-docs/02-application/security/credential-inventory.md`
