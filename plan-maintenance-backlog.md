## Назначение

Этот документ фиксирует список второстепенных задач категории G, не блокирующих основную разработку, но необходимых для поддержания качества проекта, читабельности документации и удобства операций. Задачи выполняются параллельно с основными сессиями категорий B (диагностика/BLE) и C (отчёты/платежи).

- **Статус**: В работе, блокер AGP 8.4.1

### Категория C — Отчёты и платежи

- Сессия 12: Полная реализация ReportService на Kotlin
- **Статус**: Выполнено (Session 12, 23.11.2025)

### Категория G — Документация и инфраструктура
- Сессии 1G–5G: Обновление документации, логов, скриптов, планов
- **Статус**: В работе (Session 1G, 23.11.2025)

## Метрики контроля

### Документация
- **Покрытие**: ≥90% модулей/сервисов документированы
- **Актуальность**: обновление в течение 7 дней после изменения кода
- **Качество**: оглавление, примеры, диаграммы присутствуют

### Логи
- **Структура**: единый формат с обязательными полями
- **Checksums**: все логи имеют `.meta` файлы
- **Retention**: автоматическая очистка через 30 дней

### Скрипты
- **Работоспособность**: все скрипты проходят smoke-тест
- **Документация**: usage-примеры и комментарии актуальны
- **Версионирование**: изменения логируются

### APK Size
- **Baseline**: 5.63 MB (Session 12)
- **Цель**: ≥60 MB к Session 80
- **Контроль**: измерение на сессиях 10, 20, 40, 60, 80

### Секреты
- **Реестр**: 100% секретов зафиксированы
- **Ротация**: процедуры для всех типов секретов
- **Аудит**: проверка отсутствия в коде каждые 10 сессий

## Процедура выполнения

### Для каждой сессии G

1. **Подготовка**
   - Создать feature-ветку `copilot/session-XG-description`
   - Прочитать текущий статус в roadmap
   - Определить приоритетные задачи

2. **Выполнение**
   - Работать только с документацией/планами/логами/скриптами
   - НЕ трогать код модулей `android/feature-*`, `android/platform/bluetooth`, `android/feature-reports`, `android/app`
   - Минимум 20 файлов, ≥4000 строк суммарно

3. **Валидация**
   - `git status` показывает только целевые файловые области
   - Все новые документы имеют оглавление и дату
   - Скрипты работоспособны (dry-run или реальный запуск)

4. **Финализация**
   - Создать `SESSION_XG_SUMMARY.md`
   - Создать `android/session-logs/session-xg.md`
   - Обновить статус в `plan-80-session-roadmap.md`
   - Commit и push в PR

### Критерии качества

**Документация**:
- Markdown formatting корректен
- Ссылки рабочие
- Примеры кода валидные
- Диаграммы читабельны

**Логи**:
- JSON формат валидный
- Обязательные поля присутствуют
- Checksums соответствуют

**Скрипты**:
- PowerShell/Bash синтаксис корректен
- Параметры документированы
- Error handling присутствует

**Планы**:
- Даты актуальны
- Статусы честные
- Связи между задачами явные

## Известные блокеры

### AGP 8.4.1 недоступен
- **Воздействие**: невозможна сборка Android модулей
- **Обход**: code review без компиляции, тестирование Node.js отдельно
- **Резолюция**: ожидание доступа к Google Maven или зеркалу

### Maven зеркала неполные
- **Воздействие**: некоторые зависимости недоступны
- **Обход**: использование JitPack для сторонних библиотек
- **Резолюция**: ожидание обновления зеркал

### Отсутствие устройств для тестирования
- **Воздействие**: невозможность field-тестов
- **Обход**: DEV-моки, симуляция устройств
- **Резолюция**: приобретение тестового оборудования (Session 60+)
