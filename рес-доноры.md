# Каталоги `рес 1` — `рес 7`

Эти папки добавлены в корень репозитория как read-only слепки основных донорских проектов. Они не изменяются напрямую: нужные компоненты переносятся в модули `android/` согласно инструкциям (`.github/instructions/instructions.instructions.md`, раздел 4.1).

| Папка         | Оригинальный проект   | Основное содержимое                                                                                          | Целевые модули для интеграции                                                        |
| ------------- | --------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| `рес 1/рес 1` | QRCode-Kotlin         | KMP-библиотека генерации QR-кодов (`src/commonMain`, `src/jvmMain`, примеры backend)                         | `android/platform/camera`, `android/feature-payments` (генерация QR, шаблоны оплаты) |
| `рес 2/рес 2` | Kiosk-Launcher        | Android-лаунчер с Device Owner/Device Admin (`app/src/main/java`, `app/src/main/res`)                        | `android/feature-kiosk-mode`, `android/app`, `android/platform/ui`                   |
| `рес 3/рес 3` | KasirPraktis          | Jetpack Compose POS (экраны Home/Master Data/Transactions/QR)                                                | `android/feature-payments`, `android/app`, `android/platform/data`                   |
| `рес 4/рес 4` | Kable                 | Kotlin Multiplatform BLE-стек (`kable-core`, `kable-default-permissions`, `kable-btleplug-ffi`, логирование) | `android/feature-obd-core`, `android/platform/bluetooth`                             |
| `рес 5/рес 5` | Compose Multiplatform | Компоненты Material 3, UI best practices, html/tutorials                                                     | `android/app`, `android/platform/ui`                                                 |

| `рес 7/рес 7` | Android OBD Library   | Стек ELM327 (`obd/src/main/java`, `obd/src/main/res`, `obd/src/test`, PID/DTC каталоги)                      | `android/feature-obd-core`, `android/feature-obd-diagnostics`                        |

## Использование
1. Не изменяйте исходники внутри `рес N`. Любые правки выполняются только после копирования нужных файлов в соответствующие модули `android/`.
2. Перед каждой сессией фиксируйте прогресс в `android/scripts/session-05-archive-plan.ps1` и описывайте, какие подсекции из `рес N` перенесены.
3. Для копирования используйте команду:
   ```
   robocopy "<repo_root>\рес N\рес N\<source>" "<repo_root>\android\<target>" /E /XD .git .github .gradle build gradle .idea .run .vscode node_modules release /XF *.iml *.bat *.sh *.cmd
   ```
4. После переноса добавляйте тесты и фиксируйте изменение веса APK в отчёте сессии.

Эта таблица служит быстрым справочником по соответствию донорских папок и целевых модулей монорепозитория.
