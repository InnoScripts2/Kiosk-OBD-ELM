## Проблемы и решения

### Проблема 1: Checksums для JSON логов

**Проблема**: JSON файлы содержат поле `metadata.checksum`, но checksum вычисляется от содержимого файла → циклическая зависимость.

**Решение**: Checksum вычисляется от JSON без поля `metadata.checksum`:
```bash
jq 'del(.metadata.checksum)' session-10b.json | md5sum | awk '{print $1}'
```
Полученное значение записывается в `metadata.checksum: "md5:..."`.

### Проблема 2: Объём документации

**Проблема**: Требование ≥4000 строк суммарно — много текста для качественного содержания.

**Решение**: 
- Детальные описания форматов (`logs/README.md` ~10k строк)
- Исчерпывающий `.env.example` с комментариями для каждой переменной (~4.5k строк)
- Полная переработка `README.md` с архитектурой и быстрым стартом
- Результат: **36,582 строки** — требование перевыполнено на 814%!
