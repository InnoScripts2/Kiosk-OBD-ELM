# device-obd-kit

Комплект для работы с OBD-II адаптерами. Перенесён из `packages/device-obd` в рамках Волны D миграции (Session 18G).

## Происхождение
- **Исходный путь**: `packages/device-obd/`
- **Дата переноса**: 24.11.2025
- **Сессия**: 18G
- **Статус исходного каталога**: UTILIZED (помечен для удаления после подтверждения)

## Структура
Содержит минимальную заглушку для OBD-II протокола (package.json).

## Связь с модулями
- Используется в `android/feature-obd-core` для работы с ELM327 адаптерами
- Интерфейсы: подключение, чтение DTC, параметры авто

## Планируемая интеграция
После завершения миграции TypeScript пакетов, логика должна быть адаптирована в Kotlin через JNI-обёртку или переписана нативно.

## Использование
```bash
# Из корня репозитория
cd android/feature-obd-core/device-obd-kit
npm install
npm test
```
